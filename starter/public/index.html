Before you click

What to check if the wallet waits.

  • Open Metanet Client or another BRC-100 wallet before running actions.
  • If a permission or payment window appears, approve or deny it there.
  • The paid API needs a few spendable sats available for fees and the 3-sat payment.
  • If preflight finds the wrong app on port 3321, quit the extra wallet app and retry.
